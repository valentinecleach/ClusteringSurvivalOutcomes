# SurvivalClustering -- Personal Project

This repository contains a personal project coded in R to gain ease and experiance with both clustering and survival analysis. 

## Goals:
At this early stage of the project the primary goals are the following:
- To gain familiarity with current ML algorithms to deal with censured data
- To have understanding on recent advances in the methods
- To compare methods, using real data (breast cancer, Burginga et al. 2024?) and simulations
