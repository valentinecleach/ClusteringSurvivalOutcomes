# Survival Clustering

This repository contains a personal project coded in R to gain ease and experiance with both clustering and survival analysis. 

## Table of Contents

## Overview
This **personal project** aims to use different clustering techniques to reveal subgroups in survival data. This could be useful in the case of needing to personalise treatment strategies, or to better predict outcomes.
